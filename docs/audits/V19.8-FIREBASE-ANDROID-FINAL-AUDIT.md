## Build on Windows
1. Extract this ZIP.
2. Install Node.js LTS, JDK 17, Android Studio, Android SDK Platform 35 and Build Tools.
3. Keep `android/app/google-services.json` in place; do not replace it with a config from another Firebase project.
4. In the project root run `npm ci`.
5. Run `npm run android:build` or open the `android` folder in Android Studio and build `app`.
6. Install the resulting debug APK on a test device. Check login, existing records, permission prompts, notification token registration and push delivery before treating it as release-ready.
