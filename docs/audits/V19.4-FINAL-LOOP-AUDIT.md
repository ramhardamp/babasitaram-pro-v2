## Remaining localization gaps
**Full screen-by-screen translation is still not complete.** The mechanism only translates exact strings found in the dictionaries. Some newer BSR Pro labels, validation errors, toast messages, dynamically-generated statements/PDFs and other text lack locale entries. Automated tests verify wiring and dictionary parity, not linguistic completeness. Gujarati, Marathi, Nepali and Telugu require a full string inventory and native-language review. This build must not be described as fully translated.
