# BSR Pro V19.5.0 — Push Notifications + Android Platform Fix Loop

## Fixed in source
- Added `android/` Gradle platform scaffold for application ID `com.bsrpro.digitalkhata`, with MainActivity, manifest, styles, Gradle settings, Gradle properties and pinned Gradle 8.11.1 bootstrap launcher.
- Added native `BsrPushNotificationsPlugin` in `scripts/prepare-android.mjs`: asks Android 13+ notification permission, requests FCM registration token, and supports token deletion.
- Added `BsrFirebaseMessagingService` to display foreground/data push notifications and store refreshed tokens locally; notification channel is created when the app starts.
- Registered native push plugin before `BridgeActivity.onCreate` and added Android `POST_NOTIFICATIONS` permission and Firebase Messaging dependency.
- Added a Settings opt-in switch and “Send test notification” action. Tokens are stored only under the signed-in user's `users/{uid}/pushTokens` subcollection.
- Added owner-only Firestore token rules and callable Cloud Functions: `sendTestPush` targets only the caller; `sendPushToUser` requires the `admin: true` Firebase Auth custom claim. Invalid/unregistered tokens are cleaned up.
- Included push JS in web packaging and service-worker cache.
