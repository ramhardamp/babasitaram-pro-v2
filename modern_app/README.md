# Guru Shree Modern App Prototype

Standalone Flutter/Dart prototype for the next-generation digital khata app.

## Safety boundary
This prototype is isolated from the existing Firebase production app and contains demo-only UI/data. It does not read, migrate, edit, delete, or overwrite existing customer/transaction records.

## Targets
Android, iOS, Flutter Web/PWA, future Firebase sync, versioned migrations and safe updates.
